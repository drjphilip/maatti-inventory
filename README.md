# Maatti — Live Inventory

> 📍 Bangalore · Fresh stock, auto-updated.

A clean, mobile-friendly page that shows what's on the shelf. Pulls live data from Google Sheets — no login, no build step, just open and share.

## 🔗 Live

[https://drjphilip.github.io/maatti-inventory/](https://drjphilip.github.io/maatti-inventory/)

## ✨ Features

- Live inventory from Google Sheets — refreshes every 60s
- Search products
- In-stock items first, out-of-stock dimmed
- No login required
- Mobile-friendly

## 🛠 Setup

1. Make sure both `Inventory` and `Products` tabs are shared as **Anyone with the link can view**
2. Upload `index.html` to any static host: GitHub Pages, Netlify, Vercel
3. Done
